# SpendWise Dashboard Shell

SpendWise is a static financial dashboard designed to provide users with a simple overview of their spending and savings.

## Features

The dashboard contains:

- Sidebar navigation
- Dashboard header
- Total budget summary
- Total spending summary
- Remaining budget summary
- Six financial category cards
- Responsive layout

## Financial Categories

The dashboard includes:

1. Food
2. Transport
3. Rent
4. Entertainment
5. Savings
6. Utilities

## CSS Techniques

### CSS Grid

CSS Grid is used to create the main dashboard structure and the category card layout. The cards automatically adjust their arrangement based on screen size.

### Flexbox

Flexbox is used for the navigation menu, dashboard header, and the contents of each category card.

### Responsive Design

Media queries are used to make the dashboard responsive on tablets and mobile devices.

## Files

### index.html

Contains the structure and static content of the SpendWise dashboard.

### style.css

Contains all visual styling, including Grid, Flexbox, colors, spacing, cards, and responsive layouts.
